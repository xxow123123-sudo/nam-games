# NAM Games

بوت ديسكورد عربي للألعاب، بهوية كحلية وفضية. الإصدار الأول يتضمن المافيا وبطاقاتها الأربع، وبانر NAM Games.

## التشغيل على ويندوز

1. ثبّت Node.js 24 أو أحدث من https://nodejs.org
2. فك ضغط المشروع وافتح Terminal داخل مجلد `nam-games`.
3. أنشئ تطبيقًا من https://discord.com/developers/applications ثم افتح Bot وأنشئ توكن. احتفظ به محليًا فقط.
4. انسخ `.env.example` إلى `.env`، وأكمل DISCORD_TOKEN وCLIENT_ID (Application ID) وGUILD_ID (Server ID).
5. في Developer Portal افتح Installation أو OAuth2 URL Generator، واختر `bot` و`applications.commands`. أعط البوت الصلاحيات: View Channels، Send Messages، Embed Links، Attach Files، Read Message History، Manage Messages. افتح رابط الدعوة وأضفه لسيرفرك. لا يحتاج Administrator ولا تفعيل Message Content أو Members Intent.
6. نفّذ:

```powershell
npm ci
npm run register
npm start
```

بعد الإعداد الأول يمكنك استخدام `start.bat`. البوت يعمل ما دام الجهاز والبرنامج يعملان. للتشغيل المستمر استخدم خادم Node.js أو Docker مع قرص دائم.

7. أنشئ **رومًا مخصصًا للألعاب**. من حساب لديه Manage Server اكتب `/setup` واختر الروم. **جميع رسائل هذا الروم تحذف بعد نهاية المباراة، حتى الرسائل القديمة والمثبتة، باستثناء لوحة البوت.** لا تختَر روم محادثات عامة أو روم ملفات مهمة.
8. اضغط «لعبة جديدة» في اللوحة ثم اختر «المافيا». يصبح منشئ المباراة الليدر. لا يوجد زر «ترتيبي» ولا إيموجي في الواجهة.

## طريقة اللعب

- من ٣ إلى ٢٤ لاعبًا. الحد الأعلى للحفاظ على قائمة التصويت في حدود Discord.
- الليدر يختار ١ أو ٢ مافيا؛ اثنان يحتاجان ٥ لاعبين على الأقل. يختار أيضًا كشف بطاقات الخارجين أو إخفاءها، وتفعيل الطبيب والمحقق اختياريًا. الوضع الافتراضي مافيا واحد ومواطنون فقط، والكشف مفعّل.
- الليدر فقط يغيّر الإعدادات ويبدأ أو يلغي من اللوبي. يمكنه البدء بعد دخول ٣ لاعبين. الانضمام أو الانسحاب متاح للجميع، والليدر يلغي بدل الانسحاب.
- اللوبي يغلق تلقائيًا بعد ١٠ دقائق دون نقاط. لا تبدأ مباراتان في الروم نفسه.
- يتأكد البوت من إمكانية مراسلة اللاعبين ثم يرسل لكل واحد بطاقته سرًا. المافيا تعرف بعضها وتصلها اختيارات زملائها. لا يتسرب دور لرسائل الروم قبل موعد الكشف.
- مع ٣ لاعبين يبدأ النقاش والتصويت؛ مع ٤ فأكثر تبدأ الليلة الأولى.
- الليل ٤٥ ثانية: يجب أن يتفق جميع أفراد المافيا الأحياء على هدف واحد. التعادل أو غياب اختيار أحدهم يعني عدم تنفيذ قتل. الطبيب يحمي واحدًا، ويمكنه حماية نفسه، دون تكرار الشخص ليلتين متتاليتين. المحقق له فحص واحد فقط في الليلة ولا يغيره بعد ظهور النتيجة. بقية الأدوار تستطيع تغيير الاختيار حتى نهاية الوقت.
- النقاش ١٢٠ ثانية ثم التصويت ٤٥ ثانية. التصويت قائمة داخل الروم، وتأكيده خاص. يمكن تغيير الصوت حتى نهاية الوقت. الميت وغير المشترك لا يصوت، ولا يصوت اللاعب لنفسه. يظهر عدد المصوتين فقط أثناء التصويت ثم أعداد الأصوات لكل مرشح عند النهاية، دون كشف من صوت لمن. الامتناع لا يحسب تخطيًا. التعادل أو فوز التخطي يعني عدم إخراج أحد.
- كشف الخروج ينطبق على القتل والتصويت، ويثبت بعد البداية. في نهاية المباراة تظهر قائمة أدوار الجميع وصور البطاقات المستخدمة.
- يفوز المواطنون بخروج المافيا بالكامل؛ وتفوز المافيا إذا ساوت بقية الأحياء أو زادت عليهم.
- نقطة لكل عضو في الفريق الفائز، حتى الميت، دون نقاط للإلغاء. تحفظ SQLite النقاط لكل سيرفر وتحدّث أفضل ١٠ في اللوحة بتنسيق `1- الاسم — النقاط`، مع منع تكرار احتساب المباراة.
- بعد النتيجة بـ٣٠ ثانية ينظف الروم بالكامل وتبقى اللوحة. الرسائل القديمة تحذف واحدة واحدة لذلك قد يستغرق التنظيف وقتًا إذا كان السجل كبيرًا. أي فشل بالصلاحيات يبقي الروم مشغولًا ويعيد محاولة التنظيف، دون بدء مباراة جديدة فوقه.
- بعد إعادة تشغيل البوت تُلغى المباريات غير المكتملة دون نقاط وتُنظف الرومات. النتائج التي احتُسبت قبل التوقف لا تتكرر. اللوحة الحالية يستعاد استخدامها.
- `/cancel` يلغي المباراة في الروم دون نقاط، وهو لإدارة السيرفر. الأزرار القديمة تنتهي صلاحيتها تلقائيًا. صوت الليل للمحقق خاص به فقط.

## التخصيص والإضافة

- `assets/banner.png`: البانر المعتمد NAM / Games.
- `assets/mafia.png`, `doctor.png`, `detective.png`, `citizen.png`: البطاقات المعتمدة.
- `.env`: مدد المراحل بالثواني؛ القيم من ٥ إلى ٣٦٠٠.
- `src/index.js`: الواجهة وربط Discord واللوحة وتدفق المباراة. لإضافة لعبة أضف اختيارًا في `choose-game` ووجّه اختياره لمحرك اللعبة الجديدة قبل إنشاء جلسة المافيا.
- `src/engine.js`: قواعد المافيا مستقلة عن Discord.
- `src/store.js`: تخزين SQLite. انسخ مجلد `data` احتياطيًا، ولا تحذفه عند التحديث. شغّل نسخة واحدة فقط لكل قاعدة بيانات وتوكن.

## Docker

```bash
docker compose build
docker compose run --rm nam node src/register.js
docker compose up -d
```

البيانات تحفظ في وحدة التخزين `nam-data`. لا تستخدم `docker compose down -v` إلا إذا أردت حذف النقاط والإعدادات. ملف `.env` لا يدخل الصورة.

## التحقق

```bash
npm test
npm run check
```

تشمل الاختبارات توزيع الأدوار لجميع الأحجام، الفوز والتعادل والحماية واتفاق المافيا، دوام النقاط وعدم تكرارها، ودورة مباراة ثلاثية عبر محاكاة Discord تشمل البطاقات والكشف المخفي واللوحة والتنظيف.

**لم يربط المشروع بحساب Discord حي أثناء التسليم لعدم وجود توكن.** بعد الربط جرّب مباراة بثلاثة حسابات في روم تجريبي، ثم مباراة بطبيب ومحقق. الاختبارات المحلية لا تتحقق من صلاحيات سيرفرك أو وصول الخاص الفعلي. لا يوجد كتم تلقائي أو منع كتابة الميت؛ المشاركة بالكلام حسب اتفاق اللاعبين. لا يشغل هذا البوت مكالمات صوتية.
